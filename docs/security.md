# Security boundaries

Source files, comments, patches, transcripts and model responses are untrusted data. wy never imports application modules, executes source, runs transcript commands, or runs tests merely to analyze a repository. Git commands use argument arrays; imported revisions are resolved with `--end-of-options`. Diff application and external diff/textconv programs are not used.

Repository enumeration uses Git's tracked and non-ignored untracked files, a text-extension allowlist, a 512 KB per-file limit and a 12 MB context budget. Credential-like filenames, `.env` variants, Git internals, `.wy`, dependencies, generated build directories, binary files and symlinks are excluded. Local transcript discovery reads only session metadata. Explicit ingestion is capped at 20 MB, retains bounded observable event text, and omits private reasoning and system records.

Common API tokens, password/token assignments, bearer tokens, private key blocks and credential-bearing URLs are redacted before persistence and model input. Private-key redaction preserves line counts. Hashes refer to the original source bytes, so redaction does not make unsafe anchors appear current. Redaction cannot identify every custom credential or sensitive business value. Do not treat it as a data-loss-prevention guarantee.

Default analysis and investigation make no network requests. Model use requires `--model` and an explicitly named `WY_MODEL`. Non-loopback endpoints additionally require `WY_ALLOW_REMOTE=1` and HTTPS. Only process environment configuration is read: a repository cannot opt itself into external processing. HTTP redirects and environment proxies are disabled. Endpoint credentials in URLs are rejected. Optional bearer credentials come from `WY_PROVIDER_API_KEY` and are not persisted. Model prompts treat all supplied content as evidence, not instructions. Structured output and citation checks restrict effects, but cannot guarantee resistance to every semantic prompt injection.

SQLite and atomic JSON artifacts are created with private file modes under a private `.wy` directory. Symlinked storage and database locations are refused. Do not commit `.wy`: it contains redacted source snapshots, transcript excerpts, absolute local paths and potentially sensitive context that redaction did not recognize. This is not encrypted storage or a multi-user adversarial sandbox. Previously created file modes, concurrent filesystem replacement attacks and malicious local processes are outside the MVP threat model.

The extension requires a trusted workspace, validates cache structure and paths, checks snapshots before showing annotations, and escapes all dynamic HTML. Its webview uses a restrictive nonce-based CSP, has no external resources, and navigates only to validated source evidence inside the workspace. Transcript evidence is shown as the saved redacted excerpt rather than opening the raw potentially sensitive transcript. CLI executable configuration is machine-scoped; subprocesses use argument arrays with no shell. The extension does not execute code while displaying cached annotations.
